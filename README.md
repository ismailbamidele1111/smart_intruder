# Smart Intruder Security System

## Overview

The Smart Intruder Security System is an embedded security project designed to detect unauthorized entry using sensors and provide alerts to the user.

## Objectives

- Detect possible intruders.
- Monitor doors and entry points.
- Provide immediate alerts.
- Operate reliably in different environments.
- Provide a dashboard for monitoring when connectivity is available.

## Hardware

- Microcontroller
- mmWave radar sensor
- Reed switch
- Buzzer
- Power supply
- Other supporting electronic components

## Technologies

- Embedded Systems
- Microcontrollers
- Sensors
- IoT
